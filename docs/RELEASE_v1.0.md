# 證件照 4×6 排版 v1.0

Windows 繁體中文證件照裁切與 4×6 相紙排版工具，針對台灣常用戶政兩吋 35×45 mm 設計。

支援點選／拖入 AVIF、WebP 與常見照片格式（不含 HEIC／HEIF），縮放、0.1° 旋轉微調、自由拖移、純白補空白、戶政頭部比例輔助線與 PNG 匯出。可選兩吋 8 張、一吋等比例版 14 張，或固定上排一吋 5 張、下排兩吋 4 張混合版面。

照片均於本機處理。輸出固定 300 DPI、1800×1200 px，包含淺藍色虛線裁切框；列印應使用 4×6 相紙、100% 原尺寸。

一吋為 7:9 等比例縮小的 25×32.14 mm，非所有台灣機構通用的一吋規格。戶政照片還須符合白底、頭長 32～36 mm、五官清晰等要求；本程式不作自動資格判定。4×6 PNG 供列印用，不能直接作為線上申請的單張照片。

本次發布包含 MIT 原始碼與不含 HEIC 的 Windows x64 單一 EXE，以及授權說明 ZIP；本機 HEIC 版不上傳。需要 HEIC 者可按 docs/BUILD_HEIC.md 自行編譯，並留意額外第三方授權。安裝、使用及台灣適用規格詳見 README。

HEIC 版 `.local/heic/` 的 EXE、原始碼、封裝設定不上傳；自行編譯說明 docs/BUILD_HEIC.md 公開。
